# Max Tokens 长度控制

> ⏱️ API 入门 | 限制 AI 回答的最大长度

## 参数速查

| 数值 | 大约等于 | 适合场景 |
|------|----------|----------|
| **100** | 一两句话 | `简短回答` `标题生成` |
| **500** | 一段文字 | `邮件回复` `摘要` |
| **1000** | 一篇短文 | `文章写作` `报告` |
| **2000** | 一篇长文 | `详细分析` `长篇写作` |
| **4000+** | 一篇很长的文档 | `代码生成` `完整文档` |

> 💡 **注意：** Max Tokens 设得太短回答会被截断。建议按任务预估值 +20% 安全余量设置。
