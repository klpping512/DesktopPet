# Top-P 核采样

> 🧂 API 入门 | 控制 AI 的"词汇选择范围"

## 参数速查

| 数值 | 效果 | 类比 🍽️ |
|------|------|----------|
| **0.1** | 只考虑最可能的少数词 | 只看菜单上最受欢迎的1道菜 |
| **0.5** | 考虑中等范围的词 | 看菜单前一半的菜 |
| **0.9** | 考虑大部分词 | 看菜单上几乎所有的菜 |
| **1.0** | 考虑所有词 | 看完整个菜单 |

> 💡 **核心区别：** Temperature 调"概率分布"的缩放，Top-P 调"候选词池"的大小。通常固定一个调另一个。
