# 参数组合 场景速查

> 📋 API 入门 | 不同任务该用什么参数，一目了然

## 场景对照表

| 场景 | Temp. | Top-P | Max Tokens | 说明 |
|------|-------|-------|------------|------|
| 💻 代码生成 | **0 - 0.2** | 1.0 | 按需 | 需要准确性 |
| 🌐 翻译 | **0 - 0.3** | 1.0 | 按原文 | 需要忠实原文 |
| 📧 邮件/正式文书 | **0.2 - 0.4** | 1.0 | 300-500 | 格式规范 |
| 💬 日常问答 | **0.5 - 0.7** | 1.0 | 200-500 | 自然流畅 |
| ✍️ 文章写作 | **0.6 - 0.8** | 1.0 | 1000-2000 | 有创意但连贯 |
| 🧠 头脑风暴 | **0.8 - 1.0** | 0.9 | 500-1000 | 鼓励多样性 |
| 🎨 诗歌/创意写作 | **1.0 - 1.5** | 0.8-0.9 | 按需 | 高度创意 |

> 📌 **通用原则：** 需要确定性 → 低温 + Top-P=1.0
> 📌 需要创意 → 高温 + 降低 Top-P 限制词池
