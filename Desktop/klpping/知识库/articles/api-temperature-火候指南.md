# Temperature 火候指南

> 🔥 API 入门 | 数值越高 = 越有创意（也越不稳定）

## 火候刻度

🥶 `0` ——— `0.3` ——— `0.7` ——— `1.0` ——— `1.5+` 🔥

## 参数速查

| 数值 | 效果 | 适合场景 |
|------|------|----------|
| **0** | 最确定性，每次几乎一样 | `数据提取` `代码生成` `翻译` |
| **0.3** | 比较稳定，略有变化 | `问答` `摘要` `邮件回复` |
| **0.7** | 适中的创意 | `日常对话` `文章写作` |
| **1.0** | 较高的创意 | `创意写作` `头脑风暴` |
| **1.5+** | 非常随机，可能不太连贯 | `诗歌` `艺术创作` |

> 💡 常用区间 0.3~0.7，创意任务可拉到 1.0
