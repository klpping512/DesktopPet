# 像做菜一样调参数

> 🍳 API 入门 | Temperature · Top-P · Max Tokens

## 四大参数的烹饪类比

### 🥩 Prompt = 食材

你给什么食材，就出什么菜。

好 prompt = 新鲜食材 · 坏 prompt = 过期罐头

### 🔥 Temperature = 火候

低 = 小火慢炖 · 高 = 大火爆炒

低（0.1~0.3）稳定 · 高（0.8~1.0）创意

### 🧂 Top-P = 调料

低 = 只放盐 · 高 = 什么香料都来

低（0.1~0.3）保守 · 高（0.8~0.95）惊喜

### ⏱️ Max Tokens = 出锅时间

短 = 夹生 · 长 = 煮过头

按任务设长度，不设无限

---

> 💡 Temperature 和 Top-P 不同时调，固定一个调另一个
